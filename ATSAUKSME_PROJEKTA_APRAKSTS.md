### 2. Atbilstība iepirkuma nolikuma prasībām

> **Prasība:** *Izstrādāts elektronisks resurss – interaktīvas digitālās spēles vai viktorīnas, vai spēļu bāzētas platformas, vai interaktīvi tīmekļa risinājumi, vai interaktīvas digitālās izglītības platformas.*

| Prasības elements | Risinājums platformā "MiniMani" |
| :--- | :--- |
| **Interaktīva digitālā spēle / viktorīna** | Reāllaika sinhrona daudzspēlētāju viktorīna ar `WebSocket` protokolu (<50 ms aizture), dinamiska laika atskaite, 4 atbilžu variantu un precīzās ievades režīmi, automātiska punktu un ātruma aprēķina sistēma ar tūlītēju rezultātu atklāšanu katrā raundā. |
| **Spēļu bāzēta platforma** | Privātu un publisku spēļu istabu (lobby) ģenerēšana ar unikāliem kodiem/QR kodiem, dalībnieku demokrātiska balsošana pirms spēles par noteikumiem (>50% slieksnis), uzvarētāju pjedestāls, animācijas, profili un spēlētāju reitingi. |
| **Interaktīvs tīmekļa risinājums** | 100% pārlūkprogrammā bāzēta responsīva vienlapas lietotne (React, TypeScript, Tailwind CSS), kas pielāgota darbam jebkurā viedtālrunī, planšetē vai datorā bez lietotņu instalēšanas. |
| **Digitālās izglītības / izziņas komponente** | Izglītojoša spēle tirgus vērtību un ekonomiskās domāšanas attīstīšanai, kurā dalībnieki analizē reālus nekustamo īpašumu un preču tehniskos parametrus (platība, telpas, inženiertehniskās komunikācijas, lokācija). |

---

### 3. Tehnoloģiskais nodrošinājums

- **Frontend:** React 18, TypeScript, Tailwind CSS, Canvas Confetti.
- **Backend:** Go (Golang) augstas veiktspējas serveris ar paralēlu WebSocket dzinēju.
- **Datu bāze un glabātuve:** PostgreSQL 16 (PostGIS), Hetzner S3 mākoņglabātuve (attēlu apstrāde WebP formātā operatīvajā atmiņā bez diska noslodzes).
- **Infrastruktūra un drošība:** Nginx reversais proxy, automātisks SSL/TLS (HTTPS/WSS) un GitHub Actions CI/CD automatizācija.
